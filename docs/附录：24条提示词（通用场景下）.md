# 一、节气与传统文化类

**提示词1：立春节气海报**

一幅宁静的中国传统水墨画，描绘春日山景。一棵孤柳摇曳，嫩绿新芽从地面破土而出，两只燕子穿雾飞翔，柔和晨光洒落。笔触轻盈，宣纸质感，大片留白可供叠加文字。画面下方居中用优雅的中文书法写「立春」二字。整体氛围宁静祥和，色调以青绿和淡墨为主，高清画质。



**提示词2：谷雨节气插画**

一幅雅致的中式茶园场景，薄雾山峦上青翠茶田层层叠叠，嫩绿茶芽沾满晨露，身着汉服的采茶人专注采撷，竹林为背景。画面右侧用端正的中国书法写「谷雨」二字，下方排列三个小图标：种子、雨滴、嫩芽。整体采用水墨晕染质感，古朴典雅，文化感强，色调以青绿和暖米色为主。



**提示词3：中秋节日海报**

一幅温馨的中秋节场景，皎洁满月升起于宁静的传统庭院之上，古玉桌上陈列圆月饼，桂花飘落，一家人剪影共赏明月。背景是红金渐变的天空，带有传统祥云纹样。画面中央上方用端正的中文行书写「月圆人团圆」五个字。整体氛围喜庆温暖，色彩以暖金和深蓝为主，高清画质。



**提示词4：春节营销海报**

一幅喜庆的春节营销海报，画面中央是一只可爱的卡通金龙环绕着一组大红灯笼。灯笼上写着「龙年大吉」四个烫金大字。背景是中国红到金色的渐变，带有传统云纹和祥龙纹样。画面右下角有一枚传统红色印章。整体氛围喜庆热闹，色彩鲜艳夺目，构图饱满，高清画质。



**提示词5：新中式山水插画**

一幅新中式风格的数字艺术山水画。青绿色为主调，重峦叠嶂的山峰层层推开，近景是苍劲的松树和一座飞檐翘角的古亭，山间云雾缭绕。一轮红日从山后缓缓升起，洒下金色光芒。融合了中国传统山水画的留白气韵与现代数字绘画的精致细节。画面右上角用淡墨题诗一首。整体氛围静谧空灵，典雅大气。



**提示词6：水墨寒梅图**

一幅精妙的中国传统工笔画，寒梅傲雪图。优美梅枝绽放粉白梅花覆着薄雪，片片雪花飘落。冰蓝与暖粉色调交织，花瓣与枝干肌理精密入微。角落有传统朱红印章。下方用行草书法写「梅雪争春」四字。整体氛围清冷雅致，文人画气质，高清画质。



**提示词7：青花瓷风格插画**

一幅青花瓷风格的精美中式插画。画面中央是一只优雅的青花瓷瓶，瓶身绘制牡丹花卉和祥云纹样。钴蓝映衬洁白底色，陶瓷釉面质感微妙。背景是淡淡的云水纹样。画面底部用端正的宋体写「青韵」二字。整体氛围古典雅致，经典永恒。



**提示词8：国潮风格插画**

一幅充满活力的现代国潮插画。中国龙盘旋于现代都市天际线，传统龙纹与霓虹灯光都市元素交融。大红、明金与电光蓝配色，动感构图配以翻涌祥云纹样。画面中央用大字中文黑体写「国潮崛起」四字。整体氛围年轻高能，国风现代融合，平面设计品质。



**提示词9：工笔凤凰牡丹**

**提示词12：电商主图·运动鞋**

**提示词13：护肤品礼盒种草图**

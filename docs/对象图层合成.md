# 对象图层合成 · 设计稿

> 结论先放这：**不做"修一张图"，做"生产零件 → 摆零件"。**
> 微调 = 换零件 / 挪位置 / 滑一下，不是改像素。

## 1. 为什么换方向

- 目标用户没有绘画能力。"选区 + 笔刷 + 重绘强度"本质是要求他做美术判断（这块要留、那块要重画、边缘要过渡）——他做不到，界面上给再多参数也没用。
- 复杂图 = 少量零件 × 排列。生物课本插图、机制示意图、架构图，全是这么画出来的。细胞图里的细胞核、线粒体、高尔基体本来就是可拆的。
- 图层模型的每一步都是**离散、可逆、零随机**的：点一下换个变体，拖一下换个位置，眼睛一闭一睁就回去了。不存在"再抽一次卡"。
- 和插件已有的能力天然接得上：`assemble_captions` 加引线标签，`export_ppt` 出可编辑 PPTX——"零件 + 文字"正好是一张示意图的完整构成。

## 2. 数据模型

```
scene
├─ canvas { w, h, bg }
├─ style  { prefix, palette[], lightDir, perspective, seedBase }
├─ assets { <hash>: { file, w, h, hasAlpha } }
└─ objects[]
   ├─ id, name, kind, prompt
   ├─ variants[]   ← 同一零件的 N 个造型（透明 PNG）
   └─ instances[]  ← 画布上的摆放
      { variant, x, y, w, h, rot, opacity, flipX, shadow, tint }
```

- **object = 零件类型**（细胞核）；**variant = 具体造型**（8 个）；**instance = 摆放**（3 个细胞核各选一个 variant）。
- 场景是纯 JSON：可撤销、可存盘、可分享、可 diff。
- 图层顺序 = z 序；锁定/隐藏是图层属性，不是额外结构。

## 3. 生产管线

1. **拆解**：一句话 → 对象清单（名称、提示词、相对尺寸、层级、是否需要透明）。
2. **出零件**：统一 style 前缀 + 统一光照 + 透明底，每个对象 N 个变体。
3. **组装**：拖 / 缩 / 转 / 换。
4. **出锅**：统一调色 + 接触阴影 +（可选）低强度整图融合。
5. **标注导出**：captions / PPT / PNG。

## 4. 五个真难点与对策

| 难点 | 为什么会翻车 | 对策 |
| --- | --- | --- |
| 透明边缘 | 直接要 alpha，常带白边、毛边、半透明脏边 | **实测（1024² 细胞核）：直出 alpha 在物体外圈留了一圈 RGB≈250、alpha=255 的白边；全图 43.6% 的像素是半透明，其中 96% 近纯白；硬阈值 alpha 砍不掉——白边是"画"出来的，不是羽化。** 对策：白底/纯色底生成 → BiRefNet 抠图 → 掩膜收缩 1–2px → 边缘去色污染（despill） |
| 风格不一致 | 不同批次放一起像拼贴 | style 前缀 + seed 家族 + 统一调色板；**生成时约束 + 合成时校正**两段式 |
| 光影不一致 | 各零件光向不同，怎么摆都假 | 光向写进每个 prompt；接触阴影在合成时加（可关、可调）；出锅时可选低强度融合 |
| 尺度不一致 | 线粒体画得比细胞核还大 | 每个对象记"相对画布高度"，画布给标尺/网格/对齐线 |
| 遮挡关系 | 前后关系一眼假 | z 序 + 接触阴影；二期做"对象在下方对象上投影" |

## 5. 交互只有三个动作

**点**（选中）、**拖**（移动 / 缩放 / 旋转）、**滑**（不透明度 / 阴影 / 调色）。没有画笔，没有选区，没有蒙版。

## 6. UI

三栏 + 底栏：

```
┌ 顶栏：场景名 · 重放演示 · 导出 ────────────────────────────┐
│ 图层列表  │            画布（棋盘格透明底）  │  检查器        │
│ ◉ 细胞核1 │     拖动 / 角点缩放 / 顶部旋转   │  变体 8 格     │
│ ◉ 线粒体1 │     网格 · 对齐线 · 标尺         │  尺寸/旋转/透明 │
│ ◉ …       │                                │  层级 · 对齐    │
├ 底栏：选中对象的提示词 ………………  [重新生成 8 个] ────────────┤
```

## 7. 分期

- **P1** 场景模型 + 画布 + 变体切换（原型已跑通）。
- **P2** 透明出图 + 去背 + 一句话拆解成对象。
- **P3** 融合出锅 + 拆层（SAM2，把已有的一张图变成图层）+ 导出 PPT。
- **P4** 提示词反推 + 模板库。

## 8. 权重预算（16GB 卡）

| 模型 | 体积 | 用途 |
| --- | --- | --- |
| BiRefNet | ~1 GB | 去背，透明零件的地基 |
| SAM2 tiny | ~150 MB | 二期拆层 |
| Real-ESRGAN | ~64 MB | 小零件放大 |

合计约 1.2 GB。Qwen-Image-Edit 量化后仍要 12 GB 上下，和主模型抢同一块 16GB 显存 → 二期做"按需加载、用完卸载"，不常驻。

# 参考样例：底案 → PPT 加字 → 截图文字版

> 新增样例（用户提供）：
> - `参考样例（底案-PPT截图工作流）/weather_infographic_handdrawn_底案.png`（无文字框）
> - `参考样例（底案-PPT截图工作流）/天气预报的价值_可编辑版.pptx`（可编辑文字）
> - `参考样例（底案-PPT截图工作流）/weather_infographic_handdrawn_PPT截图文字版.png`（PPT 截图成品）

## 1. 工作流

```
出图（干净底案：无文字、无框、无气泡）
  → export_ppt：把底案放进 PPT，生成原生可编辑标注（圆角条 + 圆点虚线引导 + 底部结论）
  → 在 PowerPoint 里微调文字/位置（可加粗、换色、加图标）
  → 截图 = 最终「文字版」交付
```

相比 `assemble_captions` 直接栅格化：PPT 路线**文字可编辑、可二次修改、可发同事改**，适合正式交付。

## 2. 从样例 PPTX 解析出的设计规格

| 项 | 规格 |
|---|---|
| 画布 | 1280×720（16:9） |
| 底案放置 | left 13 / top 108 / w 1249 / h 509（上下留白，便于放标注） |
| 标注框 | 圆角矩形、**白底**、彩色 **1.5pt** 边框、尺寸约 107×45 |
| 文字 | 微软雅黑 **15pt**、颜色同边框色、居中 |
| 引导线 | **圆点虚线（ROUND_DOT）**，**3pt**，同色，无箭头 |
| 底部结论 | 白底 + 紫色 1.5pt 边框 + 紫色 15pt 文字，居中胶囊 |
| 配色 | 蓝 `#3b7ea1`、琥珀 `#c98a2b`、紫 `#8a5fbf`、绿 `#2f8f6b`、红 `#b5546a` |

## 3. 工具用法

```
export_ppt({
  base_image: '底案.png',
  labels: [
    {text:'防灾减灾', side:'left',  anchor_x:0.25, anchor_y:0.35, color:'#3b7ea1'},
    {text:'出行规划', side:'right', anchor_x:0.80, anchor_y:0.40, color:'#3b7ea1'},
    {text:'提前知晓天气 · 减少灾害与事故损失', shape:'footer', color:'#8a5fbf'}
  ],
  output_path: 'outputs'
})
```

产出 `*_标注版.pptx`：可直接打开改字、截图。

## 4. 代码位置

- `scripts/export_ppt.py`：python-pptx 生成幻灯片、图片、圆角标注、圆点虚线连接线、底部结论条
- `lib/ppt.js`：Node 侧封装（解析 python、临时 job、错误处理）
- `lib/ppt-tool.js`：工具 `export_ppt`
- `lib/skill.js` 的 `samples`：自动扫描本目录三元组（底案 / PPT / 截图）
